# To-Do List App

## 📌 Overview
This is a simple **web-based To-Do List Application** built using **HTML, CSS, and JavaScript**.  
It allows users to add, edit, delete, and mark tasks as completed. The app uses **Local Storage** to persist data even after refreshing the page.

## 🚀 Features
- Add new tasks ✅  
- Mark tasks as completed / incomplete ☑️  
- Edit tasks ✏️  
- Delete tasks ❌  
- Tasks persist using **Local Storage** 💾  
- Responsive design for mobile & desktop 📱💻  

## 📂 Project Structure
```
todo_list_app/
│── index.html    # Main HTML file
│── styles.css    # Styling (CSS)
│── script.js     # Functionality (JavaScript)
│── README.md     # Documentation
```

## 🛠️ How to Run
1. Download or clone this repository.  
2. Extract the files if downloaded as a `.zip`.  
3. Open `index.html` in any modern web browser (Chrome, Edge, Firefox).  
4. Start adding your tasks! 🎉  

## 📖 Additional Notes
- No backend is required; everything runs in the browser.  
- You can extend the app with **due dates, priorities, or categories** as extra features.
